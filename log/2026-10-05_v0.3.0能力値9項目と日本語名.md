# v0.3.0 能力値を9項目に統合/キャラ名を日本の名字に(2026-10-05)

## ユーザー指示
- キャラの名前の基本を日本人で統一
- 名前は「名字見聞録」の登録名字一覧(http://www.myshop.co.jp/japancal/fname/names01.html)から参照
- 身体/思考/人心を6軸から3軸へ変更し、内容を編集・統合

## 能力値の統合(仕様書 §23)
6軸の役割を2つずつ組み合わせた。3カテゴリとも同じ組み合わせ方。値は旧2項目の平均。

| 組み合わせ | 身体 | 思考 | 人心 |
|---|---|---|---|
| 持続+出力 | POW 剛力(体力+腕力) | INT 知力(集中+記憶) | CMD 統率(人望+掌握) |
| 精度+反応 | DEX 技量(技術力+瞬発力) | TAC 策略(策略+処理) | ELO 話術(籠絡+弁舌) |
| 範囲+知覚 | MOB 機動(脚力+感覚) | VIS 洞察(俯瞰+発想) | POL 政略(政治+読心) |

- 戦闘・兵科・統治・スカウト・撤退・卒兵の進路で使う能力値を、すべて新しい9項目に読み替えた(対応表は仕様書 §23.2)
- 新兵の得意項目は1つ(9項目中)。旧の「18項目中2つ」と同じ割合
- 戦闘経験を +1.0 → +0.5。伸びる3項目が全体に占める割合が2倍になったため

## キャラ名
- `names.js`:参照元の全約15,700件から、各行(あ〜ら行)を等間隔に約390件(漢字2〜3字・読み6文字以内)。不自然なもの(毛帽子・目移・努力・生魚・猫屋敷など)は除外。全件は写していない
- 表示は名字のみ。人物の詳細に読みを添える。在籍中の人と同じ名前はなるべく避ける
- README に出典を明記

## 古いセーブの変換
- `GameEngine.migrate()`:18項目のセーブを9項目に変換(旧2項目の平均。鍛錬中の項目・得意/不得意も対応する新項目へ)。ローマ字名は日本の名字に置き換える
- 18項目の仮データで、変換後の値・鍛錬項目(旧 CMD → 新 CMD)・名前を確認
