# v0.1.0 初版 PWA(2026-10-02)

## 目的
企画・仕様・シミュレーション一式(`app\simulation\軍編成ゲーム_移行パッケージ`)の仕様 v1.1 を、遊べる Web ゲーム(PWA)にした。

## 構成
- `engine.js`:sim.js のロジックを、月ごとに進める形に作り直した(DOM 非依存)。状態は1つの JSON(乱数の状態も含む)で、localStorage に保存できる
- `index.html`:画面(計画 / 軍 / 領地 / 報告)。英語が基本、JA ボタンで日本語。能力値はホバーで日本語名と説明

## 仕様との対応
- 月次の計画:戦の数(0〜3)、戦闘の種類、相手の3択(大国が出たら「強い」が大国に置き換わる)、統治方針、撤退方針(月単位)
- 勝算の目安:自軍戦力 ÷ 想定の敵戦力。Clash は全員、Ambush は半数、Skirmish は1小隊で概算
- スカウト:2年目以降の1月。地区の特色は年ごと。ランクが見える候補は得意カテゴリも見える。失敗は一般募集に回る
- 卒兵の進路は自動(仕様では最終的にプレイヤーが決める。未実装)

## 検証
- 10年・20ゲーム(同程度の相手、戦の種類を順に回す)で、死亡 約4人/年、年10のクラス 3.9、卒兵 約58人、スカウトの傑物 0.87人/年。シミュレーション v1.1 とほぼ同じ
- Clash だけで戦うと、死亡 8人/年・クラス 4.6(損耗は増えるが、指揮系の能力が伸びる)
- スカウトの候補のランク分布(クラス1、300ゲーム):一般 65.6% / 有望 22.5% / 逸材 7.8% / 傑物 4.1%(仕様どおり)
- 375px 幅で横スクロールなし。日本語表示・人物詳細のレーダーチャートを確認
